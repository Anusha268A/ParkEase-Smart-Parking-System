System Overview

ParkEase is a web-based smart parking system designed to streamline parking operations by providing real-time slot availability, structured booking, and centralized management without the need for physical sensors.

Key Features

User Slot Booking

Allows users to view and reserve parking slots using a visual layout.

Color-Coded Slot Status

Clearly indicates available, occupied, and blocked slots.

Booking Identification

Generates a unique booking ID for verification at entry.

Admin Control Panel

Provides administrative control over slots and reservations.

System Workflow

  1. User authentication through login
  2. Selection of parking location and vehicle type
  3. Slot selection via interactive layout
  4. Booking confirmation and ID generation
